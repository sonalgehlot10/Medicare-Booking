# Medicare Booking  
*A full-stack healthcare appointment booking platform built with React, Node.js, and MongoDB.*

**Demo:** [Watch the Loom walkthrough](https://www.loom.com/share/79807094fc24453494296ac8d31fa6ac)

---

## Overview
Medicare Booking is a web application that simplifies how patients schedule medical appointments.  
It allows users to browse available doctors, book appointments, and manage bookings through an easy-to-use dashboard.  
The backend provides secure authentication, real-time availability updates, and a robust API for managing data efficiently.

---

## Inspiration
The main motivation behind this project was to gain hands-on experience in building a complete end-to-end full-stack application.
I wanted to understand how frontend and backend systems connect, from designing APIs and managing databases to creating a responsive user interface.
The idea of a healthcare booking system was a practical way to apply these concepts, since it naturally involves multiple interacting components such as authentication, scheduling, and data handling.

---

## Tech Stack
**Frontend:** React + Vite + Tailwind CSS  
**Backend:** Node.js + Express.js  
**Database:** MongoDB  

---

## Features
- User registration and login  
- Doctor listing and appointment booking  
- View, update, and cancel appointments  
- Responsive, mobile-friendly UI  
- Real-time availability and validation

---

## What I Learned
- Designing REST APIs and connecting them to a frontend efficiently  
- Handling authentication securely using tokens and middleware  
- Managing asynchronous operations between client and server  
- Styling modular, responsive UIs
